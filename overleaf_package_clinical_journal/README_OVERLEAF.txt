Overleaf usage:
1) Upload the whole `overleaf_package_clinical_journal/` folder to Overleaf.
2) Set compiler to XeLaTeX.
3) Compile `main.tex` for the main manuscript.
4) Compile `supplement.tex` for the supplementary material.

Notes:
- `main.tex` is self-contained within this folder.
- `supplement.tex` is also self-contained within this folder.
