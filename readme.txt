-data目录下为数据：
   其中classes文件夹为Ki67的分类标签，LNM文件夹为淋巴结转移状态的分类标签，包含三个子文件夹，LNM(总的)、CentralLNM(中央区)、LateralLNM(侧方)
   imgs文件夹为通道融合后的图像数据（经之前实验测试在形态学上提取了特征三通道融合后可有效促进模型性能），建议直接使用该数据文件夹，同时也附了Bmode_imgs原始b超图像数据，如果你有更好地数据预处理方式也欢迎尝试；mask文件夹为对应病灶的掩膜图像，用于Dataloader时提取ROI
   图片统一命名为："ID号_a_b_c"。ID号即为HISID号（即汇总表格里的登记号）；a为患者的第n次检查，只有一次则为1；b为患者该次检查的第n张图；c为患者该次检查中该图像为横切面还是纵切面，1为纵切面，2为横切面。
   表"【三批数据汇总】超声病理临床表格"为原始临床信息汇总表含三个子表，表"(withLNM)data3_clinical_huizong"为梳理后的结构化临床信息，表"lnm_clinical_features"为编码后的临床特征用于输入网络

-datasets目录下为数据加载代码，可根据实际需要修改

-code目录下为我之前写的初步的某个版本的LNM状态预测代码，可以基于此优化改进
